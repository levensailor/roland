# Changelog

## 2026-09-22 — Roland TM-2 sample loader

Convert dropped audio to metadata-free 44.1 kHz / 16-bit PCM WAV files and write them to a mounted SD card using the official `Roland/TM-2/WAVE` folder tree, with a brutalist drag-and-drop web UI and on-screen reminders for formatting the card and assigning pads on the TM-2.
