How to load samples on the TM-2

The module does not copy WAVs into internal memory. It plays them from the SD card. If you skip a step you get NO CARD, NO WAVE, or FORMAT.

Legal file

  • WAV only: 44.1 kHz, 16-bit, mono or stereo.
  • Path must be Roland/TM-2/WAVE. One folder level under WAVE. 300 folders, 300 files each.
  • ASCII names. No Japanese or other double-byte characters.
  • SD or SDHC, 32 GB or smaller. Format the card on the TM-2 the first time.

1. Format a new card on the TM-2

  1. Insert the card with power off, then turn the TM-2 on. Use a card you keep only for this module.
  2. Hold SHIFT + INST. Select SD CARD FORMAT, press +, confirm with +, then press TRIG IN 2.
  3. Power off before you pull the card. Hot-swap can corrupt it.

2. Write with this app

  1. Mount the card here and press Init WAVE tree.
  2. Drop audio onto a folder. This app converts and strips DAW tags.
  3. Eject the card. Insert it with the TM-2 powered off. Leave it in during play.

3. Assign a WAV to a pad

  1. Use - + to pick a kit.
  2. Press INST. Strike the pad, or press TRIG IN 1 / 2. SHIFT + TRIG IN selects the rim.
  3. Hold SHIFT + -/+ to jump from INT to SD and between folders. Then - + to the file.
  4. Strike to audition. Press INST to return. The kit saves automatically.

4. If you rename or move a file

  1. The pad path breaks and the screen shows NO WAVE. Assign the file again.

Screen messages

FORMAT
Wrong type or leftover tags. Re-save through this app.
NO WAVE
File missing or renamed. Reassign the pad.
NO CARD
Card not inserted. Samples will not play.
SD CARD LOCKED
Slide the lock switch off before writing.
